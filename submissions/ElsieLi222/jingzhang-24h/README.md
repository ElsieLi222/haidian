# JINGZHANG 24H｜京张24H

**一个人的一天 × 一座城市的学习**  
**A Day of a Person × A City that Learns**

## Project｜项目

JINGZHANG 24H 是围绕京张铁路遗址公共空间与海淀 AI 创新带提出的城市设计研究与设计提案。它以一个人的日常体验与城市持续学习的双重 24 小时，组织创新、出行、共享和城市生活之间的关系。

## Core Framework｜核心框架

- **FLOW｜畅行网络**：连续路径、多口接入与不同速度协调。
- **COMMONS｜城市共享系统**：通过开放边界、时间复用和功能混合共享既有资源。
- **LEARNING｜城市学习系统**：从使用、测试、运营与公众反馈中持续学习，先试，再改。

## Key Areas｜重点片区

- **TEST｜众智园**：真实城市测试。
- **ORIGIN｜五道口**：知识走出校园、历史道口转译为当代城市接口。
- **INTEGRATE｜大钟寺**：创新融入产业与城市生活。
